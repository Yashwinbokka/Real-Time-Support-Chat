# Real-Time Support Chat

A simple medium-sized real-time customer support chat project built with Flask and Flask-SocketIO.

## Features
- User name entry
- Real-time messaging
- Join notifications
- Online status
- Simple responsive interface
- No database, so it stays easy to understand

## Run on Windows

1. Open Command Prompt in this project folder.
2. Create a virtual environment:
   python -m venv venv

3. Activate it:
   venv\Scripts\activate

4. Install packages:
   pip install -r requirements.txt

5. Start the server:
   python app.py

6. Open this in your browser:
   http://127.0.0.1:5000

To test real-time chat, open the address in two browser tabs and join with different names.
